Scroll-Driven Animations

CSS scroll-driven animations let you tie keyframes to the scroll progress of a container or an element's visibility — no JavaScript, no scroll listeners. Scroll down to see it in action.

Browser support

Supported ✓ Your browser supports animation-timeline. The bar at the top and the cards below are scroll-driven. Not supported This browser doesn't support scroll-driven animations yet. Try the latest Chrome/Edge.

Scroll-timeline progress bar

The top bar maps the document's scroll position to scaleX() via scroll(root block).

View-timeline reveals

Each card animates as it enters the viewport using animation-timeline: view().

3

Zero JavaScript

All motion here is declarative CSS. No requestAnimationFrame, no scroll events, no jank.

4

Range-based control

animation-range: entry 0% cover 38% defines exactly when the reveal plays.

5

Accessible by default

Respects prefers-reduced-motion so motion-sensitive users aren't affected.

How it works

/* Progress bar tied to the document scroll */
@keyframes grow-progress { from { transform: scaleX(0); } to { transform: scaleX(1); } }

.progress-bar {
  animation: grow-progress auto linear;
  animation-timeline: scroll(root block);
  transform-origin: left;
}

/* Reveal cards as they scroll into view */
.reveal-card {
  animation: reveal linear both;
  animation-timeline: view();
  animation-range: entry 0% cover 38%;
}
