Container Queries

Media queries respond to the viewport. Container queries let a component respond to the size of its own parent — so the same component can be reused anywhere and adapt automatically.

Try it

Drag the slider to resize the container. The card switches between a stacked and a wide layout based on its container's width — the viewport never changes.

How it works

/* 1. Declare an element as a query container */
.cq-wrapper { container-type: inline-size; }

/* 2. Style children based on the CONTAINER's width */
@container (min-width: 420px) {
  .product { grid-template-columns: 200px 1fr; }
}
