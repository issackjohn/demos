Web Crypto Hashing

crypto.subtle.digest() computes cryptographic hashes natively in the browser. Everything below runs locally — your text never leaves the page.

🔒 crypto.subtle is only available in secure contexts (HTTPS or localhost). On GitHub Pages it's served over HTTPS, so it works.

How it works

async function hash(text, algo = 'SHA-256') {
  const data = new TextEncoder().encode(text);
  const digest = await crypto.subtle.digest(algo, data);
  return [...new Uint8Array(digest)]
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
}
