Intersection Observer

IntersectionObserver asynchronously reports when elements enter or leave the viewport — perfect for lazy-loading, reveal animations and analytics, without expensive scroll listeners.

Scroll — each panel fades in as it crosses the viewport, and its live intersection ratio updates in real time.

How it works

const observer = new IntersectionObserver((entries) => {
  for (const entry of entries) {
    entry.target.classList.toggle('in-view', entry.isIntersecting);
    const pct = Math.round(entry.intersectionRatio * 100);
    entry.target.querySelector('.ratio').textContent = pct + '%';
  }
}, { threshold: [0, 0.25, 0.5, 0.75, 1] });

document.querySelectorAll('.observe').forEach(el => observer.observe(el));
