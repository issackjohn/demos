Clipboard & Web Share

The async Clipboard API and the Web Share API let pages copy content and open the native OS share sheet — securely, and only in response to a user gesture.

1 · Copy to clipboard

Edit the text below, then copy it with navigator.clipboard.writeText().

2 · Native share sheet

Invoke the OS share UI with the Web Share API. Falls back to copying the link where unsupported (most desktops).

How it works

// Copy
await navigator.clipboard.writeText(textarea.value);

// Read (requires permission)
const text = await navigator.clipboard.readText();

// Native share with graceful fallback
if (navigator.share) {
  await navigator.share({ title, text, url: location.href });
} else {
  await navigator.clipboard.writeText(location.href);
}
