JSON Module Error Sanitization Bug

When you import invalid JSON as a module, the error V8 surfaces is heavily sanitized — no line, no column, no parse detail — even though the exact same file parsed manually yields a precise error. This page runs both paths live so you can see the difference.

The intentionally-broken JSON

We try to load this file (note the missing comma before "missingComma"):

{
  "name": "JSON Module Error Test",
  "version": "1.0.0",
  "properties": {
    "test": true,
    "count": 42
  } "missingComma": true
}
